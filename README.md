# Balajee Trade Link — website (GitHub Pages)

Static site served from this `gh-pages` branch. Orders placed from the cart are turned into a PDF
(SKU, Product Description, U/M, Qty Ordered) and emailed through FormSubmit.

- Product catalog: `products.json` (wholesale prices and warehouse stock removed)
- Order email endpoint: `ORDER_ENDPOINT` near the top of the script in `index.html`
